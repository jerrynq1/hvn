Kết nối cTrader Open API

Nhập thông tin ứng dụng cTrader Open API của bạn (Client ID, Client Secret lấy ở trang Applications của Spotware; Access Token lấy bằng OAuth cho tài khoản cần dùng). Trình duyệt nối thẳng tới live/demo.ctraderapi.com:5036, không qua worker.

Key được lưu trong localStorage của trình duyệt này, chỉ dùng để test ở máy cá nhân. Đừng đưa bản này lên hosting công khai.
